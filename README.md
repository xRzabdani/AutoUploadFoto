# UploadManis Project 🚀

Aplikasi desktop berbasis Python untuk mempercepat proses kompresi dan penyalinan file secara massal.

## 🛠️ Teknologi yang Digunakan
- **Bahasa:** Python 3
- **GUI:** CustomTkinter
- **Konkurensi:** ThreadPoolExecutor (concurrent.futures), Threading
- **Utilitas:** os, shutil

## ✨ Fitur Utama
- Pemrosesan multithreading yang membuat kompresi banyak file jauh lebih cepat.
- Antarmuka pengguna (UI) yang responsif dan modern.
- Log sistem *real-time* untuk memantau file yang sukses atau gagal diproses.

## 🚀 Cara Menjalankan Aplikasi
1. Clone repositori ini: `git clone https://github.com/xRzabdani/UploadManis_Project.git`
2. Instal dependensi: `pip install customtkinter`
3. Jalankan program: `python main.py`
